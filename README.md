# SAATH Care · v2

This release is the supplied `Saath-Care.html`, copied byte-for-byte to `index.html` so static hosts serve it at the site root.

Open `index.html` directly or host this folder with any static file server. The page includes its own CSS, JavaScript, images, and audio. Google Fonts are optional external resources; system fonts are the fallback.

This is a fictional, browser-local crisis-care demonstration. Cases, identity checks, coordinator actions, chats, map/tracking, and assistance are simulated. It does not send reports, contact responders, or dispatch emergency services. Do not enter real personal information or identity documents.

The `v1` branch and `v1.0.0` tag preserve the previous prototype. The `v2` branch contains this release.
