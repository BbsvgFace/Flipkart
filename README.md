# Saath Care · v2 redesign

A ward-level care network prototype for Kanpur. Neighbours report a need by voice or a short form; verified volunteers take the tasks that fit their zone and skills; the person who reported sees every step.

Built with **HTML, CSS and JavaScript only**. No framework, no build step.

## Open it

- **Single file:** `Saath-Care.html` is the whole prototype in one file (CSS, JS, emoji and sounds embedded). Double-click to open; no server needed.
- **Source:** `index.html` + `styles.css` + `app.js`, with `emoji/` and `sfx/` beside them. Open `index.html`, or serve the folder with any static host.

## What's in it

- **Neighbours:** language onboarding (English / हिंदी), phone sign-in, voice or form reporting with a safety check, optional photo, offline "Report saved" mode, request tracking with a live "volunteer on the way" tracker.
- **Volunteers:** status dashboard (alerts, overview, live tracking), cases filtered by zone and skill, case map with route and walking distance, full-screen map, accept / record visit / escalate, chats (volunteers, groups, authorities), and a three-step volunteer registration.
- **Everywhere:** Material 3 components on white with a blue primary, squircle corners (Chromium), liquid-orb motion, colour-coded cards, sound effects, and Hindi translations.

Use the **Prototype** button in the app to simulate no connection, switch roles or reset the data. People, places and cases are made up; nothing is sent anywhere.
